LLM INFERENCE · PERFORMANCE ENGINEERING

vLLM Speculative Decoding Cost Model

Investigated vLLM's DSpark adaptive verification cost model under continuous batching, showing that verification-token count alone misses the performance impact of KV-cache context length.

Built reproducible GPU benchmarks on RTX 4060 and H100 hardware with CUDA Graphs and FlashAttention 3, measured up to 780% context-driven latency variation, and proposed a context-aware scheduler model using token count and aggregate sequence length.

Python · vLLM · Speculative Decoding · CUDA · H100 · FlashAttention · GPU Profiling

SYSTEMS SOFTWARE · LOCAL LLM INFERENCE

LocalInferOS

Built a minimal BusyBox-based operating system that boots from a 16 GB USB directly into a Rust terminal interface for private, CPU-only local LLM inference through llama.cpp.

Profiles CPU and RAM with llama-bench, estimates tokens per second and memory fit across 15 quantized GGUF models, manages resumable Hugging Face downloads, and persists per-machine profiles and chat history on the USB data partition.

Rust · BusyBox · llama.cpp · GGUF · Hugging Face · QEMU · Systems
